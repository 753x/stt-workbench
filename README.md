# STT 워크벤치

유튜브 영상(또는 로컬 오디오 파일)의 발화 구간을 잡아 화자·시간·텍스트를 붙이는 전사 검수 툴입니다.
브라우저에서만 동작하며, 오디오·CSV·작업 내용은 서버로 전송되지 않고 사용하는 컴퓨터에만 남습니다.

## 시작하기

1. 위 링크를 열면 바로 작업 화면이 뜹니다. 설치나 로그인이 필요 없습니다.
2. **오디오 불러오기**: "파일 선택"으로 로컬 오디오 파일(m4a/wav/mp3)을 고르거나, 유튜브 링크를 붙여넣고 "불러오기"를 누릅니다.
3. **기존 작업 CSV가 있으면**: 툴바의 "가져오기/내보내기 ▾"를 열어 CSV 파일을 선택합니다.
   (번호/화자/start/end/duration/stt 컬럼을 자동으로 인식합니다.)
4. 화면 안내(우측 상단 `?` 버튼)를 참고해 구간을 잡고 화자·텍스트를 입력합니다.
5. **작업이 끝나면**: "가져오기/내보내기 ▾" → "CSV 다운로드"로 결과 파일을 받아 **드라이브에 직접 업로드**합니다.
   - 시간 표시가 Excel에서 이상하게 보이면(예: `0:00:04`로 축약) "CSV 다운로드 (Excel용)"을 대신 쓰세요.

## 자동 저장에 대해

- 작업 중인 내용은 **이 브라우저**에 자동 저장됩니다(다른 브라우저나 다른 컴퓨터로는 이어지지 않습니다).
- 오디오 파일도 새로고침 후 "이전 오디오 복원" 버튼으로 다시 불러올 수 있습니다(같은 브라우저에서만).
- 그래도 작업이 길어지면 중간중간 `Ctrl+S`로 JSON 백업을 받아두는 걸 권장합니다 — 브라우저 저장 공간이 지워지거나 컴퓨터를 바꿀 때 이 파일로 복구할 수 있습니다.

## 주요 단축키

- `Space`: 재생/정지
- `M` 두 번: 겹치는 구간을 놓치지 않고 우선 표시만 해두기(1패스)
- `N`: 표시해둔 구간을 하나씩 불러와 정리(2패스)
- `1`~`5` 또는 드롭다운: 화자 지정 · `L/W/E`: 자주 쓰는 간투어(웃음/어/음) 입력 — 아/예는 괄호 없이 직접 타이핑
  - **텍스트 입력 중엔** 위 단축키가 `Alt`+글자로 바뀝니다(`Alt+1~5`, `Alt+L/W/E`) — 전사 텍스트에 숫자·영문을 그대로 칠 수 있게 하기 위함
- `B`: 이 구간을 처음부터 다시 재생 · `V`: 파형 ↔ 유튜브 전환(정리 중이면 이 구간을 반복)
- `Ctrl`+휠: 파형 확대/축소(`Shift`+휠은 3배 빠른 좌우 이동)
- `Ctrl+Z`: 되돌리기 · `Ctrl+S`: 작업 내용 JSON으로 저장

자세한 단축키는 화면 우측 상단 `?` 버튼에서 확인할 수 있습니다.
